Residual Networks (ResNets) introduce identity shortcuts so that layers learn residual functions.

## Why residuals help

Training very deep networks is hard because gradients vanish. Residual blocks learn
the difference between the input and the desired mapping:

$$ H(x) = F(x) + x $$

```python
import torch
import torch.nn as nn

class BasicBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1), nn.ReLU(),
            nn.Conv2d(out_ch, out_ch, 3, padding=1)
        )

    def forward(self, x):
        return torch.relu(self.net(x) + x)
```

The skip connection ensures gradients can flow directly to earlier layers.
